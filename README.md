# Flux-il

אתר Flux-il + אפליקציית **Flux SMS Bridge** לסנכרון סמסים מ-Android למחשב.

## Flux SMS Bridge

תיקייה: [`sms-bridge/`](./sms-bridge)

```bash
npm run sms-bridge:install
npm run sms-bridge
```

ואז פתחו `http://127.0.0.1:8787` וחברו את אפליקציית Android עם קוד הצימוד.

מדריך מלא: [sms-bridge/README.md](./sms-bridge/README.md)
