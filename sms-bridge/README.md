# Flux SMS Bridge

אפליקציה שמחברת סמסים מטלפון Android למחשב בזמן אמת.

## איך זה עובד

1. **שרת מקומי במחשב** — מקבל סמסים מהטלפון ומציג אותם בדפדפן.
2. **ממשק ווב** — תיבת סמסים בעברית, עם צימוד בקוד / QR.
3. **אפליקציית Android** — מאזינה לסמסים חדשים ושולחת אותם לשרת ברשת המקומית.

> iPhone: Apple לא מאפשרת לאפליקציות צד ג׳ לקרוא SMS. ב־Mac השתמשו ב־Settings → Messages → Text Message Forwarding.

## התחלה מהירה (מחשב)

```bash
cd sms-bridge
npm install
npm start
```

פתחו בדפדפן:

- `http://127.0.0.1:8787`
- או את כתובת ה־LAN שמופיעה בטרמינל / במסך הצימוד

שמרו את **קוד הצימוד** שמוצג במסך.

### משתני סביבה (אופציונלי)

| משתנה | ברירת מחדל | תיאור |
| --- | --- | --- |
| `PORT` | `8787` | פורט השרת |
| `HOST` | `0.0.0.0` | כתובת האזנה |
| `PAIRING_CODE` | נוצר אוטומטית | קוד צימוד קבוע |

## חיבור הטלפון (Android)

1. פתחו את הפרויקט `sms-bridge/android` ב־Android Studio.
2. Build → Build APK / Run על המכשיר.
3. אשרו הרשאות SMS.
4. הזינו:
   - כתובת השרת מהמחשב, למשל `http://192.168.1.20:8787`
   - את קוד הצימוד
5. לחצו **חבר למחשב**.

הטלפון והמחשב חייבים להיות באותה רשת Wi‑Fi. בחלק מהרשתות צריך לכבות AP Isolation בנתב.

## API קצר

- `GET /api/session` — קוד צימוד, QR, כתובות LAN
- `POST /api/messages` — שליחת סמס (Header: `X-Pairing-Code`)
- `GET /api/messages` — כל ההודעות
- `WS /ws?role=desktop&code=XXXX` — עדכונים בזמן אמת למחשב

### דוגמת שליחה

```bash
curl -X POST http://127.0.0.1:8787/api/messages \
  -H 'Content-Type: application/json' \
  -H 'X-Pairing-Code: YOURCODE' \
  -d '{"address":"0501234567","body":"שלום מהטלפון","timestamp":1710000000000}'
```

## אבטחה

- הצימוד מוגן בקוד שמוצג רק במחשב שלכם.
- התעבורה היא ברשת המקומית (HTTP). לשימוש באינטרנט הציבורי יש להוסיף HTTPS ואימות חזק יותר.
- ההודעות נשמרות בזיכרון השרת בלבד (עד 500) ולא נכתבות לקובץ.
